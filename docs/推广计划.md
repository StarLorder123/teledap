# TeleDAP 推广计划

### 1.1 README.md 更新

当前 README 需要同步以下改动：

- [ ] 加入 HTTP/SSE 模式说明（启动方式、协议流程、多客户端共享）

- [ ] 工具数量从 24 更新为 30（含 OpenOCD 5 个工具 + `list_breakpoints`）
- [ ] 架构图和状态图更新为 tri-mode（HTTP/SSE、stdio MCP、CLI）
- [ ] 增加与 Claude Desktop / Cursor / Cline 等常见 AI 客户端的集成示例
- [ ] 增加“5 分钟快速开始”段落

## 4. 安全与远程化

### 4.1 当前限制

- HTTP/SSE 模式目前无认证、无 TLS。
- **不要直接暴露到公网**。

### 4.2 可选增强

- [ ] API Key 认证（HTTP header 或 query param）
- [ ] mTLS 支持
- [ ] 绑定地址可配置（默认 `0.0.0.0`，可改为 `127.0.0.1`）
- [ ] CORS 配置
